# XAI Intelligence Workspace

A premium AI-powered SaaS landing page built with Next.js, Tailwind CSS, Framer Motion and React Three Fiber.

## ✨ Features

- Premium Dark UI
- Fully Responsive
- Interactive Hero Section
- AI Insight Workflow
- Analytics Dashboard
- Animated Charts
- 3D Inspired Graphics
- Smooth Scroll
- Cursor Glow Effect
- Modern Footer

## 🛠 Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- React Three Fiber

---

## Installation

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Production Build

```bash
npm run build
```

Run Production

```bash
npm start
```
